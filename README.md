# Wave Spawner

Тестове завдання для Mind Studios Games: проста система хвиль ворогів у Unity.

Вороги з'являються зверху хвилями й рухаються вниз. Гравець знищує їх кліком. Наступна хвиля починається, коли всі вороги поточної хвилі заспавнені та знищені і минула задана затримка. Після останньої хвилі з'являється повідомлення про завершення гри.

## Запуск

1. Unity **6000.3.25f1** або новіша.
2. Відкрийте сцену `Assets/Main/Scenes/SampleScene.unity`.
3. Натисніть **Play** і клікайте по ворогах.

Сторонні пакети не використовуються. Залежності: Input System, uGUI + TextMeshPro, URP 2D. Усі вони з реєстру Unity.

## Налаштування

| Що | Де |
|---|---|
| Хвилі: кількість ворогів, інтервал спавну, затримка перед наступною хвилею, типи ворогів | `Assets/Main/Configs/WavesConfig.asset` |
| Швидкість і напрям руху ворога | `Assets/Main/Configs/EnemyConfig.asset` (призначається на префабі ворога) |
| Межі ігрової зони | `BoxCollider2D` на об'єкті `PlayArea` у сцені |
| Відступ точки спавну від країв зони | `PlayArea → Spawn Inset` |
| Розміри пулу | `EnemySpawner → Pool Capacity / Pool Max Size` |

Для кожної хвилі можна вказати кілька префабів ворогів. Під час спавну префаб обирається випадково. Хвиля без префабів пропускається з попередженням у консолі.
